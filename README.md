# Word Garden · Synonym Mini Quiz

เว็บแอปฝึกคำศัพท์อังกฤษ–ไทยสำหรับมือถือและคอมพิวเตอร์ มีรายการเริ่มต้น 84 คู่ เรียงตามรายการต้นฉบับ และแบ่งชุดละไม่เกิน 10 ข้อ

## เล่นควิซ

- ก่อนตอบ: เห็นคำศัพท์อังกฤษ คำอ่านไทย และตัวเลือก 4 ข้อ
- คำตอบเป็น “คำศัพท์ 2” ของคู่เดียวกัน ส่วนตัวลวงสุ่มจากคำศัพท์ 2 ของคู่อื่นทั่วทั้งรายการ
- ไม่ใช้ตัวเลือกที่ซ้ำกันหรือมีข้อความคำตอบร่วมกันในวลีที่คั่นด้วย / เป็นตัวลวง
- หลังตรวจ: เห็นเฉลย คำอ่าน คำแปลไทย และหมายเหตุการใช้
- เมื่อจบชุด: เห็นคะแนน เฉลยทั้งหมด และทบทวนเฉพาะข้อผิดได้
- คงลำดับคำถามตามรายการ สุ่มเฉพาะตัวเลือกและตำแหน่งคำตอบ
- คะแนนสูงสุดและการทำค้างบันทึกในเบราว์เซอร์

## แก้คำศัพท์เอง

เปิดเมนู **แก้คำศัพท์** แล้วกรอก:

1. คำศัพท์ 1: คำที่ใช้เป็นโจทย์
2. คำศัพท์ 2: คำตอบที่ต้องจับคู่
3. คำแปลภาษาไทย: แสดงหลังตรวจคำตอบ

เพิ่มคำอ่านไทยและหมายเหตุได้ในช่องเสริม คำใหม่ที่ยังไม่ได้กรอกคำอ่านจะแสดง “ยังไม่ใส่คำอ่าน” ไม่สร้างคำอ่านโดยอัตโนมัติ

แก้ไขและลบแต่ละคู่ได้ ต้องมีอย่างน้อย 4 คู่ และคำตอบไม่ซ้ำกัน การแก้รายการจะเริ่มคะแนนและควิซที่ค้างใหม่ เพื่อไม่ปะปนคะแนนจากคนละรายการ

ข้อมูลบันทึกใน localStorage เฉพาะเครื่อง/เบราว์เซอร์ ไม่มีการซิงก์ระหว่างอุปกรณ์ ใช้ปุ่ม **สำรอง / นำเข้ารายการ** คัดลอก JSON เพื่อย้ายข้อมูลไปเครื่องอื่น การนำเข้าจะแทนที่รายการในเครื่องปลายทาง และไม่รวมคะแนน

## ข้อมูลเริ่มต้น

- แก้คำสะกดเป็น fortified → strengthened และ relatable
- แยก sophisticated → complicated เป็นอีกคู่ตามลำดับเดิม
- คำอ่านไทยเป็นเสียงโดยประมาณ
- คู่ที่ใกล้เคียงกันเฉพาะบริบทมีหมายเหตุเพิ่มเติม เช่น pose/create, relevant/essential และ abandon/repeal
- ผู้เพิ่มคำควรตรวจความหมายด้วยตนเอง ระบบตรวจคำตอบจากคู่ที่บันทึกไว้ ไม่วิเคราะห์ความเป็นคำพ้องอัตโนมัติ

## พัฒนาและเผยแพร่

เป็น static HTML/CSS/JS ไม่มี dependencies สำหรับรันแอป วาง index.html, styles.css, data.js, app.js และ .nojekyll ที่ราก repository

ตั้ง GitHub Pages: Settings → Pages → Source: Deploy from a branch → main → /(root) → Save

ตรวจสอบตรรกะด้วย Node.js:

```sh
node check.cjs
```

การตรวจครอบคลุม 84 คู่ ลำดับ 9 ชุด ตัวเลือก การให้คะแนน ทบทวนข้อผิด ทำต่อ CRUD คำศัพท์ การตรวจข้อมูล นำเข้า/สำรอง การบันทึก และการแสดงข้อความอย่างปลอดภัย

ไม่มี analytics, บัญชีผู้เล่น หรือการส่งคำศัพท์ส่วนตัวไปเซิร์ฟเวอร์
